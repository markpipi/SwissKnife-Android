# Swiss Knife for Android

Два отдельных приложения для оформления экрана блокировки ColorOS 17 через LSPosed:

| Приложение | Назначение | Пакет | Статус |
| --- | --- | --- | --- |
| **Swiss Knife PIN 1.5** | Тема цифровой клавиатуры из `.passthm`, предпросмотр и импорт | `dev.biom.swisskey` | Применение и импорт подтверждены на OnePlus Ace 6T с ColorOS 17 |
| **Swiss Clock 1.0** | Предпросмотр и настройка шрифта, цвета, размера и положения часов | `dev.biom.swissclock` | APK собран и подпись проверена; применение на устройстве ещё не подтверждено |

Это неофициальная Android-адаптация идеи Swiss Knife. Приложения работают независимо, не меняют ввод PIN и не сохраняют введённый пароль. Часы Always On Display не затрагиваются.

## Установка

1. Скачайте **оба APK** из раздела Releases: `SwissKey-ColorOS17-1.5-debug.apk` и `SwissClock-ColorOS17-1.0-debug.apk`. Для установки требуется Android 10 или новее; проверка выполнялась для ColorOS 17.
2. Установите APK. В LSPosed включите каждый установленный модуль для `com.android.systemui` («Системный интерфейс»).
3. Откройте Swiss Knife, импортируйте `.passthm` или оставьте встроенную MaterialYou и нажмите **«Применить тему PIN»**.
4. Откройте Swiss Clock, настройте часы в живом предпросмотре и нажмите **«Применить часы»**. Предоставьте root для перезапуска SystemUI. Проверьте экран блокировки.
5. Для возврата стандартного вида используйте кнопки выключения в соответствующем приложении.

Если ранее установлена объединённая версия Swiss Knife 2.0 (`dev.biom.swisskey`), удалите её перед установкой отдельной версии PIN 1.5: подпись отличается, а версия пакета ниже. После удаления пользовательскую `.passthm` нужно импортировать заново. Swiss Clock ставится рядом с PIN приложением и не требует его удаления.

Если часы не изменились, откройте экран блокировки, вернитесь в Swiss Clock и нажмите **«Скопировать диагностику»**. По именам обнаруженных компонентов можно добавить адаптер для конкретной сборки ColorOS. Модуль часов оформляет текстовые компоненты экрана блокировки и не подменяет источник времени.

## Сборка

### PIN

Нужны JDK 21, Android SDK Platform 36 и Build Tools 36.0.0. Распакуйте `SwissKnife-Android-GitHub-ready.zip` из релиза. Из каталога `pin`:

```sh
./gradlew :app:assembleDebug
```

### Часы

Нужны JDK 21, Android SDK Platform 35 и Build Tools 35.0.0. Из корня распакованного архива:

```sh
export JAVA_HOME=/path/to/jdk-21
export ANDROID_HOME=/path/to/android-sdk
./build-clock.sh
```

Скрипт генерирует временные заглушки Xposed API только для компиляции; они не входят в APK. Подписанный APK релиза собран отдельным от PIN отладочным ключом. Для обновлений поверх опубликованного APK нужно использовать тот же ключ; новый локальный ключ создаст сборку с другой подписью.

## Исходники

Полный проект находится в `SwissKnife-Android-GitHub-ready.zip` во вкладке Releases. В нём:

- `pin/` — исходники приложения и LSPosed модуля для цифровой клавиатуры.
- `clock/` — исходники отдельного приложения и LSPosed модуля часов.
- `build-clock.sh` — автономная сборка часов из Android SDK без Gradle.
- `RELEASE_NOTES.md` — состав выпуска и контрольные суммы APK.

Иконка адаптирована из предоставленного пользователем IPA; встроенная тема MaterialYou — из предоставленного `.passthm`. Эти ресурсы не сопровождаются отдельной лицензией. Исходный iOS IPA в репозиторий не включён.
