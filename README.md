# Swiss Knife для Android

Приложение для оформления цифровой клавиатуры на экране блокировки ColorOS 17 через LSPosed. Импортирует темы `.passthm`, показывает предпросмотр и применяет оформление PIN-клавиатуры.

Применение темы и импорт проверены на OnePlus Ace 6T с ColorOS 17. Пакет приложения: `dev.biom.swisskey`.

## Установка

1. Скачайте `SwissKey-ColorOS17-1.5-debug.apk` из [релиза](../../releases/tag/v1.0.0) и установите его.
2. В LSPosed включите модуль Swiss Knife для `com.android.systemui` («Системный интерфейс»).
3. Откройте Swiss Knife, импортируйте `.passthm` или оставьте встроенную тему MaterialYou, затем нажмите «Применить тему PIN».
4. Проверьте экран блокировки. Для возврата стандартного вида выключите тему в приложении.

Если ранее установлена объединённая версия Swiss Knife 2.0 с тем же пакетом, удалите её перед установкой 1.5: подписи и номера версий отличаются. После удаления импортируйте пользовательскую тему заново.

## Исходники и сборка

Архив `SwissKnife-Android-1.5-source.zip` находится в [релизе](../../releases/tag/v1.0.0). В нём Android-проект приложения и модуля LSPosed. Для сборки нужны JDK 21, Android SDK Platform 36 и Build Tools 36.0.0:

```sh
./gradlew :app:assembleDebug
```

Новый локальный отладочный ключ даёт другую подпись APK; такой APK не установится поверх опубликованного без удаления предыдущей версии.

Иконка адаптирована из предоставленного пользователем IPA; встроенная тема MaterialYou — из предоставленного `.passthm`. Исходный iOS IPA в проект не включён.
